# Cupidon — demo

Try it: **https://hashenami-bit.github.io/cupidon-demo/**

Demo mode: no real Google login and no real money. Letters are saved only in your own browser.

1. Press **Try the demo**, then **Write a new letter**.
2. Fill it in, press **Done**, then pay on the test page (no money).
3. Press **Open it like she will**, type the 4-digit code and go through her side.

Use the UZ / RU / EN switch in the corner to change the language.
